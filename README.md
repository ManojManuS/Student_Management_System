# Student Marks Management System

## About the Project

A simple Core Java project that manages student details and marks using Encapsulation.

## Features

- Store student name and roll number.
- Enter and update marks for 5 subjects.
- Calculate total marks and percentage.
- Display grade and report card.
- Validate marks between 0 and 100.

## Technologies Used

- Java (Core Java)
- OOP Concepts
- Encapsulation
- Scanner Class

## How to Run

1. Compile the Java files:
   javac Student.java StudentMarksManagementSystem.java
2. Run the program:
   java StudentMarksManagementSystem

## OOP Concept

Private variables protect student data, while public methods provide controlled access and validation.
